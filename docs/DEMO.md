## 确认前更正信息

在待确认任务点击“修改报修信息”，表单会预填当前房间、位置和故障。修改后点击“保存修改，重新核对”。
任务仍处于待确认，原task_id和request_id保持不变，不会创建工单。刷新后查看原任务，应显示修改后的字段；再次确认才写入。
修改表单直接保存用户明确字段，不重新调用模型猜测。已完成、已取消或尚待缺项补充的任务不允许使用此入口。
示例：A101厨房漏水 → 修改为B202卧室灯不亮 → 保存 → 刷新查看 → 再确认 → 核对工单为新信息。
